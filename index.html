A 产品 它是什么 · 解决什么
01

核心特性

基础功能开箱即用；证据增强层默认全关，需要时再开。

▤

举报 GUI

玩家开举报工作台：选对象 → 选分类 → 填详情 → 确认。管理端独立界面，支持认领、关闭、重开、删除、导出。

✎

管理受理工作流

认领 → 处理 → 结案。优先级与 SLA 超时提醒，结案裁决：成立 / 不成立 / 重复 / 证据不足。

≣

异步持久化

举报、证据、审计全部异步落盘。reports.json 采用 WAL + 周期压缩，高频操作只追加一行。

🛡

审计日志

管理操作全量记录，按天分文件，保留天数与自动清理可配。每个管理动作可回溯。

◈

证据增强层

上下文快照、移动轨迹、自动检测、联动处罚，全部独立开关、默认关闭，关闭时入口一次判断直接返回。

⇄

对话与通知

玩家与管理员可在举报下互相回复；离线队列补发、关注列表提醒、Discord Webhook 推送。

举报 GUI 流程
1选择玩家在线 / 离线目标列表
→
2选择分类7 个内置分类，语言跟随切换
→
3填写详情长度与非法字符自动校验
→
4确认提交入队异步落盘 + 通知

每个分类项的图标、名称与描述随 language 配置切换；提交瞬间可选采集目标现场快照（默认关闭）。

03

证据增强层

全部默认关闭，关闭时不注册高频事件、不做额外主线程计算。想开哪块开哪块。

默认关

现场快照

提交瞬间异步采集目标位置、游戏模式、血量、物品栏、聊天、ping。

默认关

方块破坏采样

启用后才注册 BlockBreakEvent，内存保留每玩家最近破坏样本。

默认关

移动轨迹

启用后才注册 PlayerMoveEvent，按 tick 采样，结案后 GUI 回放。

默认关

自动检测

阈值触发自动报告，只生成举报 / 通知，不会处罚。

默认关

联动处罚

结案后按裁决执行预设命令，占位符 %player% %reason% %verdict%…

权限节点

reportdesk.admin 是管理总闸；无权限时不会执行操作，只提示"没有权限"。

节点说明默认
reportdesk.report提交举报（/report）所有人
reportdesk.bypass.limits绕过冷却与每日上限关闭
reportdesk.bypass.evidence不被增强层采集关闭
reportdesk.admin管理总闸（/reports）op
reportdesk.admin.close关闭 / 重开举报op
reportdesk.admin.delete删除 / 清除op
reportdesk.notify接收新举报通知op
reportdesk.evidence查看证据快照op
reportdesk.reload / config重载 / 游戏内改配置op
reportdesk.watch关注列表op
05

配置

所有业务阈值都在 config.yml，代码不硬编码。缺失或非法值自动回退默认并告警。

限流 limits

命令冷却 1000ms · 举报冷却 60s · 每日上限 10 · 同目标间隔 300s · 重复窗口 600s · 同目标未处理 ≤3

保留与自动处理

已结案保留 90 天 · 超时 14 天自动结案 · 维护任务每 30 分钟 · 分页 10 / GUI 28

优先级与 SLA

urgent 2h · high 6h · normal 24h · low 72h；惯犯达 3 条未处理自动提升到 high

游戏内改配置

/reports config set <路径> <值>，写前自动备份 config.yml，失败自动回滚

Webhook

Discord 异步推送 created / claimed / closed 事件，10s 超时，默认关闭

分类

7 个内置分类可增删，键名即分类 ID，display 为兜底值、语言文件优先

06

多语言

全部自带文案放在 lang/*.yml，通过 MiniMessage 渲染。改 language 即可切换。

三层合并

  1. bundled — jar 内置语言文件，保证升级后新 key 一定在
  2. fallback — 另一份内置语言，结构兜底
  3. primary — 磁盘上的 plugins/ReportDesk/lang/<language>.yml，管理员自定义

分类本地化

分类名 / 描述优先读语言文件 categories.<id>.name，取不到才回落 config 的 display。"内置 7 分类"切语言会跟着变；自己新增的分类没写语言条目时自动用 config 值。

安全渲染

占位符用 %name% 记法，渲染时自动转成未解析占位符 —— 玩家输入不会被当作 MiniMessage 解析，杜绝格式注入。

07

架构

纯逻辑层与 Bukkit 胶水层分离，184 单测全部跑在无 Bukkit 依赖的 JVM 上。

线程模型

主线程命令 / GUI / 事件 · 零文件 IO
存储线程池reports.json · WAL · 审计 · 证据落盘
维护任务自动关闭 · SLA 检查 · 清理过期数据
WebhooksendAsync，10s 超时，非阻塞

存储格式

reports.json     权威数据（周期压缩产物）
reports.log      WAL 追加日志（每行一条）
evidence/        证据快照（按举报 id）
audit/           审计日志（按天分文件）
pending-notices  离线举报人待补发通知

模块分层

command/   命令层（薄）
core/      纯逻辑（可单测，无 Bukkit）
service/   胶水层（Bukkit 交互）
storage/   文件 / 审计 / CSV 导出
gui/       玩家 GUI + 管理 GUI
i18n/      Messages + 900+ key 常量

安装

无外部依赖，Gson / Adventure / MiniMessage 均由 Paper 提供。

1

放入插件

把 ReportDesk-1.0.0.jar 丢进服务端 plugins/ 目录。

2

启动

服务器生成 plugins/ReportDesk/config.yml 与语言文件。

3

开始使用

玩家 /report，管理员 /reports。增强层默认关，需要哪块开哪块。

服务端Paper 1.20 – 1.21.x（api-version '1.20'）
JDKJava 17+
许可GPL-3.0-or-later
热加载/reports reload（除 storage.directory 外）
